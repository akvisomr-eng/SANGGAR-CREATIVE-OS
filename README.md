# SANGGAR CREATIVE OS

SANGGAR CREATIVE OS is a global-ready, AI-powered personal Creative & Learning Operating System.

It is primarily a **web application for users**, complemented by a **native Android application for users on phones and tablets**, while the public website serves as the **company/brand, SEO and entry portal**.

## Product model

- **Public Website** — company profile, product information, SEO/content, public resources and entry point to SANGGAR.
- **SANGGAR Web Application** — primary user workspace for learning, creating, practicing, improving, proving skills, building portfolios and accessing opportunities.
- **SANGGAR Android App** — user companion for smartphones/tablets, using device capabilities such as camera, microphone, notifications and mobile interaction.
- **Platform / Back Office** — governed organization, administration, security, legal, finance, compliance and operational capabilities behind the user experience.

SANGGAR is not positioned as an administrative school application. Administrative and enterprise functions are supporting platform layers, while the product experience is user-first.

## Core lifecycle

Learn → Create → Practice → Improve → Prove → Publish → Connect → Work → Grow → Govern → Evolve

## Product principles

- User-first experience.
- One SANGGAR identity and governed data foundation.
- Web application as the primary user workspace.
- Android as a first-class user companion.
- Public website separated from the authenticated application experience.
- Global by architecture, local by policy and localization.
- AI-native, human-governed.
- Evidence-based skills and portfolio.
- Privacy, security, child safety, intellectual property and compliance by design.
- Autonomous improvement with controlled release gates.
- GitHub + Supabase are the current core engineering infrastructure.
