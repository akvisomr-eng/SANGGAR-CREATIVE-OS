# SANGGAR CREATIVE OS

SANGGAR CREATIVE OS is a global-ready Creative, Learning, Business and AI Operating System.

## Core lifecycle
Learn → Create → Improve → Prove → Publish → Sell → Work → Grow → Operate → Govern → Evolve

## Product principles
- Global by architecture, local by policy and localization.
- One identity, one governed data platform, many journeys.
- AI-native, human-governed.
- Autonomous improvement with controlled release gates.
- Privacy, security, child safety, intellectual property and compliance by design.
- Web-first foundation with Android/mobile as a first-class client.
- GitHub + Supabase are the current core engineering infrastructure.
