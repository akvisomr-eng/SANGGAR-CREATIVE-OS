# SANGGAR CREATIVE OS — Certification & Launch Readiness Matrix

## Priority 1 — Indonesia
- Business entity and licensing
- NIB / OSS
- Applicable KBLI
- PSE Lingkup Privat registration
- PDP compliance
- Terms, privacy, consent and consumer documentation
- IP/copyright/licensing
- Security and incident response
- Child/minor safeguards where applicable

## Priority 2 — International trust
- ISO/IEC 27001 readiness/certification
- ISO/IEC 27701 readiness/certification
- ISO/IEC 42001 readiness/certification
- ISO 9001 where useful for organizational quality
- ISO 22301 where continuity requirements justify it
- ISO/IEC 20000-1 where service-management certification has commercial value

## Priority 3 — Jurisdiction expansion
For every target country/region:
1. determine applicability
2. identify regulator
3. identify registration/licence/notification
4. identify privacy requirements
5. identify AI requirements
6. identify tax/commerce requirements
7. identify education/child requirements
8. identify IP requirements
9. create evidence package
10. submit through official channel
11. track decision
12. monitor changes

## Certification principle

Certification is an independent external process. SANGGAR provides the management system, controls and evidence required for assessment; an accredited/competent external body performs the certification assessment where certification is sought.

## Release gate

A global production release must have:
- security gate
- privacy gate
- AI governance gate
- legal/compliance gate
- business continuity gate
- data governance gate
- accessibility gate
- operational readiness gate

No single certificate replaces regulatory compliance.
