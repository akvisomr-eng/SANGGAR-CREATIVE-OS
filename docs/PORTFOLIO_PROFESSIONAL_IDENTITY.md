# Portfolio & Professional Identity Layer

This layer turns learning outcomes, projects, evidence, and credentials into a controlled professional presentation.

## Chain

Learning → Skill → Evidence → Project → Portfolio → Creative Passport

## Portfolio

A user can maintain one or more portfolios for different goals: creative work, professional work, learning outcomes, or public presentation. Portfolio items reference existing projects and evidence instead of duplicating them.

## Credentials

Credentials represent certificates, awards, licenses, course completion, and other achievements. They are separate from skill claims so a certificate is not automatically treated as proof of practical ability.

## Publishing

Portfolio and passport visibility are explicit. Private source material is not exposed merely because a user publishes a portfolio.

## Future economic connections

This layer becomes the presentation and trust foundation for:
- freelance/project opportunities
- marketplace listings
- recruitment and talent discovery
- client proposals
- professional networking
- creator monetization
- business services
- Creative Passport sharing

The next major layer is the economic opportunity layer: marketplace, offers, projects, transactions, and later career/recruitment.
