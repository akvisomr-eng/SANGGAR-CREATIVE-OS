# SANGGAR Generative AI Intelligence

SANGGAR integrates the architectural patterns of `aishwaryanr/awesome-generative-ai-guide` as a **Generative AI Intelligence Layer**. The upstream guide is organized around using AI, building AI systems, understanding AI research, interview preparation, courses and topics including LLM foundations, prompting/context, RAG, fine-tuning, agents, evaluation/observability, multimodal AI, production/LLMOps and safety/security.

SANGGAR does not copy the upstream course catalogue or third-party content into the product. It translates the learning and engineering structure into native SANGGAR capabilities.

## 1. Use AI → Creator AI Copilot

Creators should be able to move from intent to useful AI action:

```
INTENT
 ↓
CONTEXT
 ↓
TOOL / MODEL SELECTION
 ↓
PROMPT / INSTRUCTIONS
 ↓
EXECUTION
 ↓
EVALUATION
 ↓
MEMORY

```

Examples:
- writing and content
- portfolio curation
- research
- creative ideation
- business planning
- marketplace proposals
- learning support
- automation

- consistency
- latency


## 6. AI Observability

- model
- request type
- latency
- token/usage data where available
- estimated cost
- errors
- tool calls

- user feedback

This feeds CTO Intelligence and Data Intelligence.
