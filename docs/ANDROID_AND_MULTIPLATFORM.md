# SANGGAR CREATIVE OS — Android & Multiplatform Strategy

Android is a first-class client, not a secondary wrapper.

## Shared platform contract

Business logic, identity, authorization, AI orchestration, data policy and core workflows remain server/platform governed.

Clients provide:
- experience
- device capabilities
- offline/cache behavior
- notifications
- camera/microphone/sensors where authorized
- secure local storage
- platform-specific UX

## Android priorities

Initial capability families:
- SANGGAR ID/auth
- dashboard
- learning
- creative workspace
- portfolio
- messaging/notifications
- AI assistant
- evidence capture
- camera/media ingestion
- offline-aware workflows

## Future device readiness

The capability-adapter model should allow later support for:
- iOS
- desktop
- smart glasses
- vehicle interfaces
- other connected devices

A new device should consume the same governed capability contracts instead of forcing a platform rewrite.

## Adaptive UX

The UI must adapt to:
- screen size
- orientation
- accessibility
- user role
- user skill level
- workflow context
- language/locale

Adaptation must remain predictable and accessible.
