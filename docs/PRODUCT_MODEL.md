# SANGGAR CREATIVE OS — Product Model

## Product definition

SANGGAR CREATIVE OS is a user-first web platform with a native Android companion. It provides a personal digital environment for learning, creativity, skill development, evidence, portfolio, opportunities and continuous growth.

It is not positioned primarily as an administrative application.

## Product surfaces

| Surface | Primary purpose | Main audience |
|---|---|---|
| Public Website | Company profile, SEO, public information, resources, entry portal | Public, partners, prospective users |
| Web Application | Main authenticated workspace | Students, individuals, creators, professionals and organizational users |
| Android App | Mobile user companion | Smartphone/tablet users |
| Platform/Back Office | Governance and operational support | Authorized organization/platform operators |

## User journey

Learn → Create → Practice → Improve → Prove → Publish → Connect → Work → Grow

## Core user capabilities

- SANGGAR ID
- personal workspace
- AI assistant
- learning
- creative projects
- skill development
- evidence
- competency
- portfolio
- Creative Passport
- collaboration
- opportunities/career
- notifications
- personal settings
- mobile capture and voice through Android

## Organization support

Schools, institutions and companies can operate programs and organizational workflows through governed platform/back-office capabilities.

These capabilities support the user experience; they do not redefine SANGGAR as an administrative school application.

## Product boundary

The public website is not the authenticated application.
The Android app is not the administration console.
The web application is the primary broad user workspace.
The platform/back office provides governance and enterprise support.

## Long-term direction

The same identity, data and capability contracts should support future clients and devices without requiring a rewrite of the core platform.
