# Learning, Skill Graph, Evidence & Creative Passport

This layer turns SANGGAR from a place to store activity into a system that can connect learning, demonstrated ability, and professional identity.

## Core chain

User → Learning → Skill → Competency → Project → Evidence → Portfolio → Creative Passport

## Learning

Learning paths contain structured modules such as lessons, practice, projects, assessments, reflections, and resources. Enrollments and progress track a user's journey without duplicating project or evidence data.

## Skill Graph

Skills are connected to broader competencies. A user skill records level and the nature of the claim:
- self-declared
- observed
- inferred
- assessed
- verified

This distinction is intentional: SANGGAR must never present an assumption as a proven fact.

## Evidence

Evidence links a claimed skill to something concrete: a project, assignment, assessment, credential, work, publication, review, or other source. Evidence keeps provenance so future verification can trace where a claim came from.

## Creative Passport

Creative Passport is a portable professional identity built from selected skills, projects, evidence, credentials, and portfolio items. It is more than a CV: it can become a trusted representation of what a person can do and what supports that claim.

## Privacy principle

Private learning, locker content, projects, and evidence remain private by default. Public sharing is explicit. A public passport must not automatically expose private source data.

## Future connections

This foundation is intentionally reusable by:
- courses and academies
- mentors and assessments
- portfolio
- marketplace and freelance work
- career and recruitment
- organization talent development
- AI recommendations
- verification and reputation
- interoperability and data portability

The layer is a foundation, not a claim that every future module is already implemented.
